# Services du systeme du PC, lances par init2 avant la console (et relances
# s'ils tombent sur une erreur).
# pseudo-terminaux (docs/VTERM.md) : la console texte et telnetd s'en servent
/sys/svc/vterm
# le reseau (docs/RESEAU.md) : wlan0 du Wi-Fi (iwl), DHCP, DNS, NTP ; avant le son, comme sur le Pi
/sys/svc/netd
# le clavier PS/2 (i8042 : le clavier interne du portable) et la souris PS/2 du
# port auxiliaire (le touchpad en mode herite, s'il y repond), inscrits aupres
# de hidmanager comme un clavier et une souris USB ; rien ne les annonce (ni
# pcid ni usbd), le service se lance donc ici (il s'arrete sans erreur s'il n'y
# a pas de controleur, ou si le moniteur du noyau le tient ; sans souris, il
# garde le clavier seul)
/sys/svc/ps2kbd
# le son (docs/SON.md, docs/etude/SON-PC.md) : melange, volumes, sortie principale ; les
# pilotes (hda, usbaudio) s'y inscrivent, lances par hwmanager
/sys/svc/sound
# (authd, l'elevation : lance par init2 lui-meme, docs/etude/MULTI-UTILISATEUR.md 2.6)
# les mises a jour des paquets (docs/PAQUETS.md) : une fois par jour, quand le reseau et l'heure sont la ;
# en uid 0, seul ecrivain de /bin, /apps, /sys (docs/etude/MULTI-UTILISATEUR.md 2.7)
/sys/pkgd
# la batterie et le secteur (ACPICA : _BST, _BIX, _PSR), les alertes de batterie faible et le profil
# d'energie des coeurs (docs/etude/BATTERIE-PC.md, /etc/power.ini) ; sans batterie, il reste a
# repondre (commande battery)
/sys/svc/acpid
# le journal d'audit (E56 du plan de securite) : /var/log/auth.log, les lignes du journal du noyau qui comptent
# pour la securite (elevations, connexions, refus de vfs, commits de paquets), en ajout seulement
/sys/svc/auditd
