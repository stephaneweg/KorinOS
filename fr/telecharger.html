Obtenir Korin OS

Sur un PC, Korin s'installe depuis une clé USB. Sur un Raspberry Pi 4, il démarre sur une carte microSD. Une fois installé, l'app Logiciels le tient à jour depuis le dépôt signé en ligne.

PC : la clé USB d'installation

La clé démarre un Korin complet en mémoire, puis lance Setup en mode installation : choix du disque et des partitions, des composants, du clavier, du Wi-Fi et de la région, puis création du premier compte.

Ce qu'il faut

  • Un PC x86-64 avec UEFI, Secure Boot désactivé
  • Un disque NVMe interne avec de la place pour une partition Korin (Windows peut rester ; sa partition EFI n'est jamais écrite)
  • Une clé USB plus grande que l'image, environ 320 Mo (elle est effacée)
  • Pour l'instant, un matériel proche du ZBook Fury 17 G8 : Wi-Fi Intel AX201, graphisme Intel, HD Audio

Télécharger

L'image de la clé d'installation n'est pas encore publiée. En attendant, on la construit depuis les sources, sous Windows (son contenu vient des paquets publiés) :

python -I tools/pc/keyroot.py
python -I tools/pc/installkey.py build --sysroot build/pc/keyroot/root `
    --esp build/pc/keyroot/esp --repo build/pc/keyroot/repo
.\tools\pc\installkey.ps1 list
.\tools\pc\installkey.ps1 write -Disk N   # en administrateur

installkey.ps1 refuse tout disque qui n'est pas sur l'USB, le disque système de Windows et les disques plus petits que l'image.

Installer

  1. Brancher la clé et démarrer le PC dessus (F9 ouvre le menu de démarrage des portables HP).
  2. Setup démarre. Choisir le plan du disque : Korin a sa propre partition FAT32 ; les partitions existantes ne sont touchées que si vous le demandez.
  3. Choisir les composants, se connecter au Wi-Fi pour les paquets en ligne, et créer son compte.
  4. Korin s'ajoute au menu de démarrage UEFI. Son propre menu propose aussi Windows s'il est sur le disque.

L'installateur n'a encore servi que sur un portable. Faites une sauvegarde avant de l'essayer sur le vôtre, et gardez les outils de récupération de Windows sous la main.

Raspberry Pi 4 : images de carte

Deux images de 4 Go avec une partition FAT32, compressées en xz.

Korin OS (lite)

Le système de base ; les apps s'ajoutent ensuite par Logiciels. 12 Mo à télécharger.

korin_lite.img.xz

Korin OS (full)

La plupart des paquets déjà installés (sauf GCC, .NET et les jeux SDL). 89 Mo à télécharger.

korin_full.img.xz

Avec Raspberry Pi Imager, ajouter ce dépôt dans ses options (« Content repository », adresse personnalisée) pour voir Korin dans la liste, avec les sommes de contrôle :

https://stephaneweg.github.io/KorinOS/img/os-list.json

Ou choisir « Use custom » et prendre le .img.xz téléchargé.

Ces images datent du 7 novembre 2026. Elles précèdent l'arbre de fichiers unique et les comptes d'utilisateurs. Après le premier démarrage, ouvrez Logiciels et installez les mises à jour du dépôt du Pi.

L'essayer dans QEMU

Les deux machines tournent sous QEMU depuis les sources : .\build.ps1 run pour le Pi (raspi4b), tools/pc/qemu_pc.py et tools/pc/qemu_nvme.py pour le PC (q35 avec UEFI). QEMU n'offre pas de GPU à Korin : la 3D y est logicielle ou absente. Voir docs/CONSTRUIRE.md.
