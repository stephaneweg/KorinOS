Get Korin OS

On a PC, Korin installs from a USB key. On a Raspberry Pi 4, it runs from a microSD card. Once installed, the Software app keeps it up to date from the signed online repository.

PC: the USB install key

The key starts a complete Korin in memory, then runs Setup in install mode: choose the disk and partitions, the components, the keyboard, Wi-Fi and region, and create the first account.

What you need

  • An x86-64 PC with UEFI, Secure Boot turned off
  • An internal NVMe disk with free space for a Korin partition (Windows can stay; its EFI partition is never written)
  • A USB key larger than the image, about 320 MB (it is erased)
  • Hardware close to the ZBook Fury 17 G8 for now: Intel Wi-Fi AX201, Intel graphics, HD Audio

Download

The install key image is not published yet. Until it is, build it from the source tree on Windows (the published packages are used for its content):

python -I tools/pc/keyroot.py
python -I tools/pc/installkey.py build --sysroot build/pc/keyroot/root `
    --esp build/pc/keyroot/esp --repo build/pc/keyroot/repo
.\tools\pc\installkey.ps1 list
.\tools\pc\installkey.ps1 write -Disk N   # as administrator

installkey.ps1 refuses any disk that is not on USB, the Windows system disk, and disks smaller than the image.

Installing

  1. Plug in the key and start the PC from it (F9 on HP laptops opens the boot menu).
  2. Setup starts. Pick the disk plan: Korin gets its own FAT32 partition; existing partitions are only touched if you say so.
  3. Choose the components, connect to Wi-Fi if you want the online packages, and create your account.
  4. Korin adds itself to the UEFI boot menu. Its own menu also offers Windows when it is on the disk.

The installer has been used on one laptop so far. Back up your data before you try it on yours, and keep Windows' recovery tools at hand.

Raspberry Pi 4: card images

Two images, both 4 GB with one FAT32 partition, compressed with xz.

Korin OS (lite)

The base system; add apps later with Software. 12 MB to download.

korin_lite.img.xz

Korin OS (full)

Most packages already installed (not GCC, .NET or the SDL games). 89 MB to download.

korin_full.img.xz

With Raspberry Pi Imager, add this repository in its options (“Content repository”, custom URL) to see Korin in the list, with checksums:

https://stephaneweg.github.io/KorinOS/img/os-list.json

Or choose “Use custom” and pick the downloaded .img.xz.

These images date from 7 November 2026. They predate the single file tree and user accounts. After the first start, open Software and install the updates from the Pi repository.

Try it in QEMU

Both machines run under QEMU from the source tree: .\build.ps1 run for the Pi (raspi4b), tools/pc/qemu_pc.py and tools/pc/qemu_nvme.py for the PC (q35 with UEFI). QEMU has no GPU for Korin, so 3D falls back to software or is unavailable. See docs/CONSTRUIRE.md.
