Claude Code sur Korin PC (paquet claude-code)

claude                  le binaire officiel de Claude Code pour Linux x86-64 (glibc), tel qu'Anthropic le publie
                        sur downloads.claude.ai : téléchargé à l'installation du paquet, vérifié (taille et SHA-256
                        donnés par le paquet), jamais modifié ni redistribué par Korin.

La commande /bin/claude le lance par l'hôte Linux de Korin (/bin/linuxhost run). Vos réglages, votre connexion et vos
sessions sont dans ~/.claude, comme sous Linux. La première fois : « claude » au Terminal, puis « Claude account with
subscription » : la page de connexion d'Anthropic s'ouvre dans Jet.

Mises à jour : par le paquet (Logiciels) ; celle de Claude Code lui-même est coupée.
Conditions d'utilisation : celles d'Anthropic (https://www.anthropic.com/legal/consumer-terms).
