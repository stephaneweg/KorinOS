# Manifeste de TerraCube, le bac à sable de blocs de Korin (src/apps/terracube/README.md)
name     = TerraCube
category = Jeux
description = TerraCube, bac à sable de blocs en 3D par le GPU : explorer un monde sans fin, construire en mode créatif, miner et fabriquer ses outils en mode survie, faire couler l'eau et la lave, bâtir des circuits de cuivre (pistons, répéteurs, observateurs), élever des animaux, apprivoiser un loup, survivre aux créatures de la nuit ; pilotable par Python, BASIC ou un agent IA (MCP).
keywords = jeu cubes blocs voxel construire bac à sable 3d monde minage circuits pistons lave animaux créatures survie python basic mcp agent
help = Cliquez dans la vue pour jouer (Échap rend la souris). ZQSD ou les flèches pour marcher, la souris pour regarder, Espace pour sauter, Maj pour s'accroupir, Ctrl pour courir.
help = Clic gauche : casser ; clic droit : poser le bloc choisi ; 1 à 9 ou la molette : choisir ; B : la liste des blocs ; I : en créatif, le catalogue de tous les objets ; A : prendre le bloc visé ; F : voler (Espace monte, Maj descend).
help = Mode survie (Partie > Mode survie) : tenir le clic pour casser, I pour l'inventaire et la fabrication (établi, four, outils).
help = Circuits : le cuivre donne de la poudre (le fil) ; levier, bouton, torche de cuivre, répéteur, piston, lampe à signal… Clic droit pour s'en servir, Maj + clic droit pour poser contre eux.
help = Survie : cœurs et faim au-dessus de la barre ; clic droit pour manger, nourrir un animal, apprivoiser un loup avec des os (clic droit encore : il garde ou il suit) ; clic gauche pour frapper.
help = T : la console de commandes (time 18, weather rain, mode survival, give, craft, help) ; F3 : infos détaillées ; F9 : plein écran.
help = Pilotage : Python (import terracube) et BASIC sur le port 4730 ; un agent IA par Pilotage > Piloter par un agent IA (MCP, port 7312). Exemples dans /apps/terracube.app/python et /apps/terracube.app/basic.
