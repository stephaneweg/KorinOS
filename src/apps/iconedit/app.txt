# Manifeste de l'Editeur d'icones, l'Icon Editor d'Onyx
name     = Éditeur d'icônes
category = Création
description = L'Éditeur d'icônes dessine des icônes BMP au pixel, de 16 à 64 pixels de côté, le magenta servant de transparent.
keywords = icône icones pixel art bmp png dessin sprite pictogramme
help = Menu Fichier > Nouvelle 40 x 40 (Ctrl+N) ou une autre taille de 16 x 16 à 64 x 64 ; l'icône s'enregistre en BMP.
help = Outils au clavier : P crayon, L ligne, R cadre, B boîte, O ellipse, F remplir, K pipette, E gomme ; G la grille, X échange les couleurs.
help = Menu Image : retourner, tourner de 90°, décaler ou vider l'icône.
