# Météo

Le temps qu'il fait et les prévisions des quatre jours qui viennent, pour une ville.

## Choisir une ville

1. Écrivez le nom de la ville dans le premier champ (« Liège », « Lyon »…).
2. Au besoin, son pays dans le second : le nom ou le code à deux lettres (BE, FR, CH…). Utile quand plusieurs
   villes portent le même nom.
3. **Entrée**, ou le bouton **Chercher**.

La carte montre le lieu trouvé, l'heure du lieu, la température, le ressenti, l'humidité, le vent, puis les quatre
jours qui viennent (le maximum en gras, le minimum à côté). La dernière ville est gardée pour la prochaine ouverture.

## Actualiser

Les prévisions se rechargent seules toutes les 15 minutes. **Fichier > Actualiser** (Ctrl+R) les recharge tout
de suite ; **Fichier > Changer de ville** (Ctrl+L) met le curseur dans le champ de la ville.

## La carte sur le bureau

**Fichier > Afficher sur le bureau** pose la même carte sur le bureau, sous l'Agenda, derrière les fenêtres. Elle y
revient à chaque ouverture de session (elle est ajoutée à vos programmes de démarrage : Réglages, Démarrage la
montre). Un clic sur la carte ouvre Météo, pour changer de ville : la carte suit. Décochez **Afficher sur le
bureau** pour la retirer.

## Le réseau

Météo a besoin d'Internet. Sans réseau, la carte le dit et réessaie chaque minute.
