# Parking Jam

Videz le parking : chaque voiture doit sortir sur la route sans être bloquée par une autre.

## Jouer

- **Touchez ou cliquez une voiture** : elle roule dans son axe, du côté où vous l'avez touchée, jusqu'à heurter
  une voiture, un plot ou le bord, ou sortir sur la route.
- **Glissez** sur une voiture pour choisir le sens vous-même.
- Le niveau est gagné quand le parking est vide : **Niveau suivant**, ou **Rejouer ce niveau** pour faire mieux.

En haut, les flèches passent d'un niveau à l'autre parmi ceux déjà ouverts ; **Annuler** défait le dernier coup,
**Recommencer** reprend le niveau. Votre progression est gardée pour la prochaine fois.

## Bon à savoir

Parking Jam est fait avec Godot. Il a besoin du paquet **godot-templates** (Logiciels), qui contient de quoi faire
tourner les jeux Godot. Son projet est livré avec les sources de Korin, pour l'ouvrir et le modifier dans Godot.
