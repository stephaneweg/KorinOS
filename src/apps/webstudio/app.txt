# Manifeste de WebStudio, l'outil de développement web (docs/DESIGN-WEBSTUDIO.md)
name     = WebStudio
category = Développement
description = WebStudio écrit des sites web : un site est un dossier ; le serveur de Korin le sert, F5 l'ouvre dans Jet et chaque enregistrement recharge la page.
keywords = web site html css javascript serveur développement éditeur page internet webmatrix
help = Fichier > Nouveau site crée un site dans SD1:/home/sites à partir d'un modèle (huit thèmes de plus avec le paquet Modèles de sites) ; Ouvrir un dossier ouvre n'importe quel dossier.
help = F5 (Voir dans Jet) lance le serveur du site et ouvre la page dans Jet ; Ctrl+S enregistre et la page se recharge.
help = Double-clic dans l'arbre : un dossier se déplie, un fichier s'ouvre. Ctrl+Maj+F cherche dans tout le site.
help = Le journal du serveur est en bas ; double-clic sur un 404 : créer le fichier qui manque. Site > Publier ajoute le site au serveur web de ce PC.
