Introduction

{{SITE}} est un outil qui fait une seule chose, et la fait bien. Cette documentation vous mène de l'installation au premier déploiement.

Pourquoi {{SITE}} ?

Parce que les outils simples durent. {{SITE}} n'a pas de dépendance, démarre en un instant et se configure en un fichier.

Astuce Commencez par le guide « Premier projet » : dix minutes suffisent.

Un premier essai

Dans un terminal :

git clone https://exemple.be/{{SITE}}.git
cd {{SITE}}
make && ./{{SITE}} --version

Si tout va bien, la version s'affiche. Sinon, voyez Dépannage.

Attention Les versions avant 1.0 ne lisent pas le nouveau format de configuration.

Et ensuite ?

  • Installer {{SITE}} sur votre machine ;
  • le configurer pour votre projet ;
  • découvrir l'API.
