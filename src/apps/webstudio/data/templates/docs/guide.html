Installation

Trois façons d'installer {{SITE}}, de la plus simple à la plus souple.

Premier projet

Créez un dossier, puis un fichier de configuration :

mkdir mon-projet && cd mon-projet
{{SITE}} init

Configuration

Le fichier {{SITE}}.ini contient tout :

[projet]
nom     = mon-projet
sortie  = build/
journal = oui
CléValeurPar défaut
nomle nom du projetle nom du dossier
sortiele dossier produitbuild/
journalécrit ce qui se passenon

Déploiement

Copiez le dossier build/ sur votre serveur ; sur Korin, Site › Publier dans WebStudio suffit.

Astuce Gardez la configuration dans git : elle documente le projet.

Dépannage

« Commande introuvable »

Le dossier de {{SITE}} n'est pas dans le PATH : ajoutez-le, ou appelez-le par son chemin.

« Configuration illisible »

Une clé est mal écrite : {{SITE}} check dit laquelle.

API

const projet = await {{SITE}}.ouvrir('mon-projet');
projet.construire({ sortie: 'build/' });

Options

  • --verbeux : tout dire ;
  • --sec : ne rien écrire, montrer ce qui serait fait.
