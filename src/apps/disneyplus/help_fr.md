# Disney+

Regarder Disney+ dans Korin : le **site de Disney+** dans sa propre fenêtre, avec son icône, sur le moteur de Jet.
Tout ce que fait le site y est : profils, accueil, recherche, Ma liste, lecture avec sous-titres et langues.

Korin PC seulement : Disney+ protège ses vidéos par **Widevine**, le module de Google que Jet sait faire tourner sur
le PC.

## La première fois

1. **Le module Widevine** : s'il n'est pas encore là, Disney+ propose de le télécharger chez Google (environ 22 Mo,
   empreinte vérifiée) et de l'installer dans votre dossier personnel. C'est le même que celui de Jet (Réglages,
   « Lire les contenus protégés ») et de Spotify : un seul téléchargement pour tous.
2. **Votre compte** : connectez-vous dans la fenêtre, comme sur le site, puis choisissez votre profil. L'app garde
   sa session (ses cookies sont à elle, à part de ceux de Jet) : les fois suivantes, rien à refaire.

## Regarder

La fenêtre s'ouvre agrandie. **F11** (ou **Fichier > Agrandir**) l'agrandit ou la rend à sa taille.

| Touche | Effet |
|---|---|
| Espace | lecture ou pause |
| F11 | agrandir la fenêtre, ou la rendre |
| Ctrl+R, F5 | recharger la page |
| Alt+← | page précédente |
| Ctrl+W, Ctrl+Q | fermer |

## Le menu Fichier

- **Recharger**, **Précédente** : la page.
- **Agrandir** : comme F11.
- **Ouvrir dans Jet** : Disney+ dans le navigateur (avec la session de Jet).
- **Se déconnecter (effacer les données)…** : efface la session de l'app (cookies, stockage) ; celle de Jet ne change
  pas.

## Bon à savoir

- Le module Widevine tourne ici comme dans Chrome sous Linux. Disney+ y limite l'image à la **HD 720p**, comme pour tout navigateur sous Linux.
- La fluidité de la vidéo dépend du tracé de Jet, encore en cours d'amélioration sur le PC.
