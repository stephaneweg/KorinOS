Idée de l'utilisateur (3/11/2026), pour plus tard : un assistant IA pour Korin OS, inspiré de PockQI d'Onyx.

- Mistral pour le text to speech.
- Piloté uniquement au clavier.
- But principal : aider à utiliser l'OS et les apps, notamment la bureautique, comme Clippy dans Office.
- Option : un MCP dans l'OS, pour qu'une IA puisse le piloter.

**Why:** demande de l'utilisateur ; `app.txt` prévoit déjà « ses capacités, pour l'agent IA » dans ses commentaires.

**How to apply:** rien de lancé. Partir de PockQI dans le dépôt Onyx, sur UIKit sans pont ([[armpi-ports-sans-pont]]). La clé d'API de Mistral ne doit jamais aller dans un dépôt ni dans un paquet.
