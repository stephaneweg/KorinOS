Pas mesure : images montrees par l'UI avec la boucle a 10 ms, defilement, pages ordinaires. Journal par image : fichier SD:/etc/web-gpu-debug (a retirer ensuite). Piege : sub() d'enable-webgl.py saute la retouche si le texte de remplacement est deja dans le fichier. Depuis le 2/11, Jet avec WebGL est le seul Jet : tools/webkit/build-jet.sh lie toujours ANGLE et Mesa sur ~/armpi-mesa/out/webcore (tools/mesa/build-jet.sh retire). Fusionne dans main local le 2/11 (c34207e), pas de depot distant ; build/webkit/sdroot de main et ~/armpi-webkit-build/out ont ce Jet. Sur le Pi, SD0:/apps/jet.app est ce Jet (CRC EF58664D) et jetgl.app est retire ; la carte E: n'a pas ete touchee a cette occasion. Sous QEMU : Jet demarre, WebGL refuse proprement. Pas de suite de conformite, pas de page du reseau. Deploiement direct possible : FTP vers 192.168.1.20, XCRC, lancement par telnet. Paquet pour le Pi : tools/mesa/pi-package.py ; pose sur E: le 2/11, anciens fichiers dans E:/mesa-avant, retour du Pi inconnu.

Choix : v3d Gallium, pas v3dv (v3dv refuse le GPU sans TFU, CSD, multisync, file CPU). Pas de MMU V3D : bo->offset = adresse physique. BUF_NOCACHE (bit 61 de BUF_CREATE) = write-combine de Linux. V3D_OP_SUBMIT : adresses brutes, car Mesa chaine le BCL sur plusieurs BO.

Dans main (56dbfd2 puis la consolidation du 2/11 au soir) : Jet montre toute page sans recopie (deux images dans la surface, accuse DisplayDidRefresh, ui_surface_source, WS_SF_NOREDRAW), Elegant saute ce qui est sous une surface (surf_cover) : copie 2,6 -> 0,7 ms, DMA 3 a 4 ms asynchrone, three 58,9 images/s sur le Pi, systeme du Pi mis a jour par FTP (etc et donnees intacts). NE JAMAIS toucher TI_2D a l'aveugle : rafale 8 a bloque le demarrage du Pi (reseau vivant, Elegant absent ; QEMU n'utilise pas ce DMA), reparation par la carte. Avant un reglage materiel d'Elegant : prevenir l'utilisateur. Mesure par maillon d'Elegant : poser des cntpct_el0 dans compose, journal lu par SD0:/journal.txt apres `journal` (20 s).

**Why:** but final de l'utilisateur : WebKit reconstruit avec WebGL sur le GPU ; la chaine prevue devient WebKit, ANGLE, armgl, Mesa, V3D (remplace le backend ANGLE maison sans Mesa d'Onyx). ANGLE n'est pas dans ~/webkit (checkout partiel).

**How to apply:** le kernel8.img d'une carte n'est pas celui de build/ : `build.ps1 sd` l'assemble avec -d ECRAN_W=800 -d ECRAN_H=600 ; ne jamais copier build/kernel8.img (1024 x 768) sur la carte. `wsl bash -c '...'` developpe $VAR avant bash : passer par un script. Sous Git Bash, MSYS_NO_PATHCONV=1 casse les chemins /c/ pour python. Un heredoc contenant des guillemets francais casse le shell de l'outil Bash : ecrire le fichier avec Write. telnet ajoute une ligne vide apres chaque ligne de sortie. Voir [[armpi-viewport3d]], [[armpi-avalonia]], [[armpi-webkit]].
