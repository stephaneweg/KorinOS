Deux propositions pour l'écran de connexion de Korin OS

Maquettes statiques, aux jetons de UIKit (Givre et Onyx Noir : le bouton en haut à droite change le thème de toutes les maquettes). Le texte complet, les règles et la recommandation sont dans docs/DESIGN-CONNEXION.md. Rien de ceci n'existe encore dans src/.

Choix de l'utilisateur (15/11/2026) : A, la carte, sans la barre de menus. Le thème de l'écran de connexion se règle dans Réglages ; celui de chaque session est celui de son utilisateur. B reste ici pour mémoire.
